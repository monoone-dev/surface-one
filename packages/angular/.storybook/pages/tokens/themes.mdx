# Themes

The design-system **core is shadcn/ui, 1:1** — every component reads tokens, and the base values
are shadcn's own (Nova style, Neutral colours, Geist). Each **theme** is an override layer, one file
per skin × mode in `packages/tokens/src/themes/` — or one file holding both modes (rule:
`angular-zoneless.md` §6c):

| File                                                     | Skin                                                                | shadcn style |
| -------------------------------------------------------- | ------------------------------------------------------------------- | ------------ |
| `minimalist.light.theme.scss`                            | Minimalist · light — **the default / base** (`:root`)               | Nova         |
| `minimalist.dark.theme.scss`                             | Minimalist · dark                                                   | Nova         |
| `studio.light.theme.scss` / `studio.dark.theme.scss`     | Studio — lightly modernist, Nuxt UI "Sky", soft aurora gradient     | Vega         |
| `paper.light.theme.scss` / `paper.dark.theme.scss`       | Paper — tuned for reading                                           | Maia         |
| `neumorphism.theme.scss` (light and dark)                | Neumorphism — soft extruded surfaces, raised and inset shadows      | —            |
| `material.light.theme.scss` / `material.dark.theme.scss` | Material — MUI's Material Design 2: Roboto, elevation, 4px radius   | —            |
| `surface.light.theme.scss` / `surface.dark.theme.scss`   | Surface — SurfaceOne's own: tiles on hard ledges, keys, mono labels | —            |

A skin is stamped as `data-skin` on `<html>`; the mode as `data-theme` (`light` / `dark` / `system`).
The base defines every token; the other files only re-declare what differs. Switch the toolbar
**Skin** and **Theme** to see each layer live.
